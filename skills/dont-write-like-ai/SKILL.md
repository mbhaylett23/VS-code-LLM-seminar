# Dont Write Like AI

## Goal

Make the text sound like a competent human wrote it for a real audience, not like a template generated by a model.

The aim is not to make writing casual. The aim is to make it specific, direct, and useful.

## When To Use

- The text sounds generic, inflated, evasive, or too polished.
- The user asks for a less AI-like draft.
- The writing is external-facing: email, report, proposal, paper, student feedback, partner note, recommendation, or public documentation.
- A paragraph could be reused in almost any project with only the nouns changed.

## Workflow

1. Identify the audience and purpose.
2. Keep concrete facts, actions, constraints, dates, numbers, and named responsibilities.
3. Remove generic AI phrasing, inflated claims, and filler transitions.
4. Replace vague importance claims with specific mechanisms or consequences.
5. Use decision voice where appropriate: say what will happen, not what "could be explored".
6. Cut template structure: forced triplets, formulaic conclusions, repeated bullets, and decorative formatting.
7. Preserve real uncertainty, but make it concrete.
8. Return the revised text plus a short note on the main changes.

## Common AI Tells To Remove

Avoid or replace these unless they are genuinely the right word:

- delve
- intricate
- tapestry
- testament
- underscore
- pivotal
- vibrant
- profound
- multifaceted
- nuanced
- robust
- seamless
- leverage
- harness
- foster
- landscape
- journey
- crucial
- vital
- cutting-edge
- state-of-the-art

Replace inflated phrases:

| AI-like | Better |
|---|---|
| serves as | is |
| stands as | is |
| represents a key step | is a step / changes X by Y |
| plays a crucial role | does X |
| in today's fast-paced world | delete |
| unlocks new possibilities | name the actual possibility |
| enables seamless collaboration | say who collaborates and how |

## Structure Problems

Watch for:

- three adjectives in a row: "robust, scalable, and innovative"
- repeated "not just X, but Y"
- paragraphs ending with empty "-ing" phrases: "highlighting the importance of..."
- "Despite these challenges..." conclusions
- "future work" speculation that is not tied to a real plan
- too many bullets where a short paragraph would be clearer
- headings and bold text that make simple points look over-designed

## Content Problems

Fix these before style:

- Unsupported claims: "studies show", "experts agree", "it is widely recognized".
- Vague benefits: "improves outcomes", "enhances engagement", "drives impact".
- Hidden uncertainty: "to be confirmed", "TBD", "pending further details".
- Internal process leaks: "as discussed", "after revision", "updated framing", "confirmed by the AI".
- Deliberation instead of decision: "we propose to consider" when the actual plan is "we will".

If a claim needs evidence, ask for the source or mark it as needing verification.

## Better Style

Prefer:

- shorter sentences with varied rhythm
- specific nouns and verbs
- present tense for current facts
- future tense for committed actions
- plain caveats when uncertainty is real
- examples that belong to this exact project

Do not overcorrect into slang. Professional writing can still be human.

## Final Check

Before returning the text, ask:

- Could this paragraph only belong to this project or person?
- Does every sentence do work?
- Is any claim unsupported?
- Did I remove generic AI phrasing without removing useful detail?
- Would the intended reader know what to do next?

If the answer is no, revise again.
